# Knowledge architecture

The reusable vault lives in [wiki/index.md](../wiki/index.md). Sources live in [references/sources.md](../references/sources.md), and blank working templates live in [templates](../templates/private-operation-receipt.md). Open the repository root as an Obsidian vault or browse the same relative links on GitHub.

The vault is a core part of `legends-coolify`: tools collect bounded evidence, notes explain what it means, and the module recipe guides an agent to the relevant procedure through the central `cto-legends` router. No additional registered skill is required for the knowledge.

The public module contains reusable knowledge only. Completed operational receipts, private inventories, secrets, and raw incident logs belong outside this checkout. The [boundary note](../wiki/public-private-boundaries.md) explains what may be promoted into public knowledge.

See [maintenance](../wiki/knowledge-maintenance.md) for the update loop and [current focus](../wiki/hot.md) for remaining evidence gaps. This initial baseline is source-reviewed; it does not claim a recovery drill or a Brainstein audit.
