# legends-coolify agent instructions

1. Read `wiki/index.md`, then the smallest relevant playbook and its dated sources.
2. Read `docs/AGENT-RECIPE.md` before live commands. Run offline doctor, then live doctor for authorized connected work.
3. This release only inspects. Use a least-privilege read token. Never expand the allowlist to a mutating GET or add an escape hatch casually.
4. Keep credentials, raw API responses, private inventories and operational reports outside this public repository and managed sources.
5. A successful collection is not healthy infrastructure. A configured backup is not a completed backup or a tested restore. Distinguish observed, inferred and unverified claims.
6. Source-cite domain guidance and date reviews. Update links and source-ledger claim coverage when adding knowledge.
7. Run offline unit tests and `scripts/check_release.py` before release. Follow `docs/RELEASE.md` for packaging and catalog admission.
8. Use one registered `cto-legends` skill. The module recipe is loaded on demand, not installed as a separate host skill.

No public provider mutation or private-data publication is authorized by these instructions.
