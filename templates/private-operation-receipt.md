# Private operation receipt template

Copy this template to a private operator workspace before completing it. Do not commit completed receipts to the public module. Never record secret values.

- Objective:
- UTC timestamp and operator:
- Target instance/version, team and resource scope (private):
- Authorization and allowed action:
- Module version and commands used:
- Evidence locations (private):
- Observed control-plane/API result:
- Observed workload/readiness result:
- Observed public route and representative user-flow result:
- Backup evidence: schedule / execution / artifact / restore test:
- State changes, writer ownership and recovery boundary:
- Unknowns and unsupported checks:
- Decision, reason and next action:

Mark each layer observed, failed, or not checked. A successful command cannot fill every field. See [health interpretation](../wiki/inventory-and-health.md) and [public/private boundaries](../wiki/public-private-boundaries.md).
