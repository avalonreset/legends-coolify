# Support

Check [the knowledge index](wiki/index.md), [validation](docs/VALIDATION.md)
and the command's `--help` output before reporting a problem.

For defects in this module, open an issue at
[avalonreset/legends-coolify](https://github.com/avalonreset/legends-coolify/issues).
Include the module version, OS, Python version, the command with placeholders
for private identifiers, and the expected versus observed behavior.

Never post API tokens, environment values, raw provider responses, private
hostnames or operational reports. Use a minimal synthetic example where
possible. Report vulnerabilities through [the security policy](SECURITY.md).

Coolify installation, platform bugs and account questions belong with
[Coolify's documentation and support resources](https://coolify.io/docs).
This independent module does not provide a hosted service or a support
response-time guarantee.
